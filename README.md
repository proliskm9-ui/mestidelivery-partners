# 🤖 MestiDelivery Partners Bot

Telegram-бот для ресторанов-партнёров и курьеров MestiDelivery. Принимает уведомления от бэкенда и отправляет их партнёрам в Telegram **картинками-баннерами с кнопками** (вместо обычных текстовых сообщений).

## Архитектура

```
Бэкенд (Go) ──POST──► HTTP :50061 ──► рендер PNG-баннера ──► Telegram API ──► Партнёр
                                               ◄── Принять / Отклонить ◄──
```

## Структура файлов

```
Partners Bot/
├── bot.py                       # Главный файл бота
├── banner_renderer.py           # Рендер баннеров: накладывает данные на PNG-шаблоны (Pillow)
├── banners-spec-fix.json        # Попиксельная спецификация полей на баннерах
├── MestiDelivery-Banner-*.png   # 6 базовых PNG-шаблонов (1c/2a/3a/4a/5a/6a)
├── fonts/                       # ArchivoBlack / Unbounded / Manrope (Google Fonts)
├── requirements.txt             # Python зависимости
├── .env                         # Конфигурация (токены, порты)
├── partners_bot.db              # SQLite база данных (создаётся автоматически)
└── venv/                        # Виртуальное окружение
```

## Запуск

```powershell
# Активировать venv и запустить
.\venv\Scripts\python bot.py
```

## HTTP API (для бэкенда)

### `POST /api/bot/v1/restaurant/new-order`

Уведомление о новом заказе. Требует заголовок `X-Bot-Security-Token`.

**Тело запроса:**
```json
{
    "order_id": 1004,
    "restaurant_id": "rest-pizza-house",
    "restaurant_telegram_id": 123456789,
    "total_amount": 900.0,
    "currency": "сом",
    "customer_name": "Иван Иванов",
    "phone": "+996700000000",
    "address": "ул. Ленина 1, кв. 5",
    "comment": "Позвоните при входе",
    "payment_method": "Карта",
    "delivery_fee": 150.0,
    "items": [
        {"name": "Маргарита", "quantity": 2, "price": 450.0}
    ]
}
```

**Ответ:**
```json
{"ok": true, "message_id": 42}
```

### `GET /api/bot/v1/partners`

Список зарегистрированных ресторанов. Требует `X-Bot-Security-Token`.

### `GET /healthz`

Проверка работоспособности. Возвращает `ok`.

## Команды бота (для партнёров в Telegram)

| Команда                        | Описание                                      |
|--------------------------------|-----------------------------------------------|
| `/start`                       | Приветствие и проверка регистрации            |
| `/register <ID ресторана>`     | Привязать ресторан к текущему чату            |
| `/status`                      | Проверить статус подключения                  |
| `/help`                        | Список команд                                 |

### Регистрация ресторана

1. Откройте бот `@MestiDelivery_Robot` в Telegram
2. Напишите `/register rest-pizza-house` (ID из бэкенда)
3. Готово — заказы будут приходить в этот чат

## Поток обработки заказа

```
1. Бэкенд POST /api/bot/v1/restaurant/new-order
2. Бот ищет telegram_id ресторана (из запроса или из БД)
3. Бот рендерит PNG-баннер нового заказа (шаблон 2a) и шлёт его фото с кнопками:
   ✅ Принять  |  ❌ Отклонить   (подпись фото — подробный состав заказа)
4. Партнёр нажимает кнопку:
   • Принять  → подпись фото меняется на «✅ Заказ принят!», кнопки убираются
   • Отклонить → баннер заменяется на шаблон «Заказ отменён» (3a), кнопки убираются
5. Бот PATCH /api/v1/orders/{id}/status на бэкенд
```

## Рендер баннеров (`banner_renderer.py`)

Все уведомления отправляются **картинками**: модуль берёт базовый PNG-шаблон и
накладывает на него динамические поля (номер заказа, сумма, адреса, имя и т.д.)
по попиксельным координатам из `banners-spec-fix.json`.

| Шаблон | Назначение | Когда используется |
|--------|------------|--------------------|
| `welcome` (1c) | Приветствие с именем партнёра (контурный текст) | Успешная авторизация |
| `order_new_restaurant` (2a) | Новый заказ ресторану | `new-order`, кнопки Принять/Отклонить |
| `order_cancelled_restaurant` (3a) | Заказ отменён | Партнёр нажал «Отклонить» |
| `order_new_courier` (5a) | Новая доставка курьеру | `broadcast` / `assign` (победитель) |
| `profile_restaurant` (4a) | Профиль ресторана | Кнопка «Профиль» (ресторатор) |
| `profile_courier` (6a) | Профиль курьера | Кнопка «Профиль» (курьер) |

Особенности рендера: переменные начертания шрифтов (weight), авто-подгон размера
текста, перенос по словам, контурный (outline) текст на welcome, пилюля рейтинга
со звездой, зачёркнутая сумма на отмене, fallback на Unbounded для кириллицы
(Archivo — только латиница). При ошибке рендера бот автоматически откатывается
к обычному текстовому сообщению, поэтому поток не ломается.

> Шрифты `ArchivoBlack.ttf`, `Unbounded.ttf`, `Manrope.ttf` должны лежать в `fonts/`.
> Для рендера нужна зависимость `Pillow` (см. `requirements.txt`).

## Совместимость с Go-ботом

Партнёрский бот (Python) работает на порту `50061`.  
Курьерский бот (Go) работает на порту `50060`.  
Они независимы, но используют **один и тот же** Telegram токен бота — это одно и то же приложение `@MestiDelivery_Robot`.

> ⚠️ Если Go-бот запущен с webhook — Python-бот автоматически удаляет webhook при старте и переключается на polling.
